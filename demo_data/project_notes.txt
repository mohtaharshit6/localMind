Project Overview: LocalMind Development Notes
==============================================
Project: LocalMind - AI Personal Assistant
Status: MVP Development
Team: Solo Developer
Target: College Demo

ARCHITECTURE DECISIONS
------------------------
After evaluating several options, we chose:

1. SQLite FTS5 as the primary search engine
   - Reason: Zero external dependencies, reliable, fast for local use
   - BM25 ranking built-in since SQLite 3.x
   - No server required, perfect for local-first architecture

2. Google Gemini as LLM provider
   - Reason: Strong performance, generous free tier
   - Fallback: App works without API key for search/indexing
   - Model: gemini-1.5-flash (fast, cost-effective)

3. Streamlit for the UI
   - Reason: Rapid development, Python-native
   - Limitation: Not suitable for production-scale apps
   - Benefit: Perfect for demos and MVPs

TECHNICAL CHALLENGES ENCOUNTERED
----------------------------------
1. FTS5 Query Sanitization
   - Problem: User input could break FTS syntax
   - Solution: Strip special characters, use phrase matching
   - Result: Robust search without injection risks

2. Large File Handling
   - Problem: PDF files can be very large
   - Solution: Chunking with overlap for context preservation
   - Chunk size: 800 chars, 100 char overlap

3. Path Security
   - Problem: Prevent path traversal attacks
   - Solution: Resolve all paths, check against whitelist
   - Implementation: auth.py module with validate_destination()
